# 🍕 Pizza Sales Analysis

An end-to-end **Pizza Sales Analysis** project using **SQL, Excel and Power BI** to analyze sales performance, customer orders, pizza categories, sizes, and business trends.

## 📌 Project Overview

This project analyzes pizza sales data to identify important business insights such as:

- Total Revenue
- Average Order Value
- Total Orders
- Total Pizzas Sold
- Average Pizzas per Order
- Daily and Monthly Sales Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Top 5 and Bottom 5 Pizzas
- Order and Revenue Performance

## 🛠️ Tools & Technologies

- **SQL / MySQL** – Data analysis and business queries
- **Microsoft Excel** – Data exploration and analysis
- **Power BI** – Interactive dashboard and visualization
- **CSV** – Dataset
